# FIX: Update ACL for existing thumbnails

## PROBLEM
Thumbnails exist but have `public: false` ACL, causing 401 errors.
We don't need to regenerate them - just update ACL!

## SOLUTION

Create a simple script to update ACL for existing thumbnails:

**File:** `server/scripts/fixThumbnailAcl.ts` (NEW)

```typescript
import { objectStorageClient } from "../objectStorage";
import { db } from "../db";
import { images } from "../../shared/schema";
import { isNotNull } from "drizzle-orm";

async function fixThumbnailAcl() {
  console.log('[FixACL] Updating ACL for existing thumbnails...');

  // Get all images with thumbnails
  const imagesWithThumbnails = await db
    .select({ thumbnailUrl: images.thumbnailUrl })
    .from(images)
    .where(isNotNull(images.thumbnailUrl));

  console.log(`[FixACL] Found ${imagesWithThumbnails.length} thumbnails`);

  for (const image of imagesWithThumbnails) {
    try {
      const thumbnailUrl = image.thumbnailUrl!;
      
      // Extract bucket and object name from /objects/uploads/{id}/thumb.webp
      const parts = thumbnailUrl.split('/');
      const uploadsIndex = parts.indexOf('uploads');
      const uploadId = parts[uploadsIndex + 1];
      
      // Get bucket from env
      const bucketName = process.env.REPLIT_OBJECT_STORAGE_BUCKET_NAME;
      if (!bucketName) {
        throw new Error('REPLIT_OBJECT_STORAGE_BUCKET_NAME not set');
      }
      
      // Construct full GCS path
      const objectPath = `public/uploads/${uploadId}/thumb.webp`;
      
      // Update ACL to public
      const bucket = objectStorageClient.bucket(bucketName);
      const file = bucket.file(objectPath);
      
      await file.makePublic();
      
      console.log(`[FixACL] ✓ Updated ACL for ${uploadId}`);
      
    } catch (error) {
      console.error(`[FixACL] ✗ Failed for ${image.thumbnailUrl}:`, error);
    }
  }

  console.log('[FixACL] Complete!');
}

fixThumbnailAcl()
  .then(() => process.exit(0))
  .catch((err) => {
    console.error(err);
    process.exit(1);
  });
RUN SCRIPT
Bash
npx tsx server/scripts/fixThumbnailAcl.ts
This will update ACL for all 20 existing thumbnails in ~5 seconds.
TESTING
After running script:
Reload gallery
Check Network tab
thumb.webp files should return 200 OK
WHY THIS WORKS
Thumbnails already exist in GCS
They just have wrong ACL (private instead of public)
file.makePublic() updates ACL without regenerating image
Much faster than regenerating (5 seconds vs 5 minutes)
