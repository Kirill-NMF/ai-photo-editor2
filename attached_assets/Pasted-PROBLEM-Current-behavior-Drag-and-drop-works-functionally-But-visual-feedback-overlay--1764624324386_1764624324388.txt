Replace with improved handlers:

TypeScript


const [isDragging, setIsDragging] = useState(false);
const dropZoneRef = useRef<HTMLDivElement>(null);

const handleDragEnter = (e: React.DragEvent) => {
  e.preventDefault();
  e.stopPropagation();
  
  // Only set dragging if we have files
  if (e.dataTransfer.types.includes('Files')) {
    setIsDragging(true);
  }
};

const handleDragOver = (e: React.DragEvent) => {
  e.preventDefault();
  e.stopPropagation();
  
  // Keep dragging state active while over drop zone
  if (e.dataTransfer.types.includes('Files')) {
    setIsDragging(true);
  }
};

const handleDragLeave = (e: React.DragEvent) => {
  e.preventDefault();
  e.stopPropagation();
  
  // Only hide overlay if we're leaving the drop zone entirely
  // Check if relatedTarget is outside drop zone
  const relatedTarget = e.relatedTarget as Node;
  
  if (dropZoneRef.current && !dropZoneRef.current.contains(relatedTarget)) {
    setIsDragging(false);
  }
};

const handleDrop = async (e: React.DragEvent) => {
  e.preventDefault();
  e.stopPropagation();
  setIsDragging(false);  // Hide overlay immediately on drop
  
  // ... existing drop logic
};


Key changes:

1.
Added dropZoneRef to track drop zone container

2.
Check e.dataTransfer.types.includes('Files') to ensure we have files

3.
In handleDragLeave, check if relatedTarget is outside drop zone

4.
In handleDragOver, keep isDragging active (prevents flickering)

TECHNICAL NOTES

Why relatedTarget check?

Problem:

Plain Text


User drags file over parent div
  → onDragEnter fires → isDragging = true ✅
User moves cursor over child element (button)
  → onDragLeave fires on parent → isDragging = false ❌
  → Overlay disappears (flickering!)


Solution:

TypeScript


const relatedTarget = e.relatedTarget as Node;
if (dropZoneRef.current && !dropZoneRef.current.contains(relatedTarget)) {
  // Only hide if we're leaving drop zone entirely
  setIsDragging(false);
}


Why pointer-events-none on overlay?

•
Overlay should not block drop events

•
Without this, drop might not work

•
Overlay is purely visual feedback

Why check e.dataTransfer.types.includes('Files')?

•
Prevents overlay from showing when dragging text, links, etc.

•
Only activate for actual file drops
