GOAL

Add database fields to track API usage and promo code status.

Time: 10 minutes
Risk: Low (additive changes only)
Testable: Yes (check database schema)




IMPLEMENTATION

Step 1: Add fields to users table

File: shared/schema.ts

Find the users table definition:

TypeScript


export const users = pgTable("users", {
  id: varchar("id").primaryKey(),
  email: varchar("email").notNull().unique(),
  name: varchar("name"),
  // ... existing fields
});


Add these new fields at the end (before closing bracket):

TypeScript


export const users = pgTable("users", {
  id: varchar("id").primaryKey(),
  email: varchar("email").notNull().unique(),
  name: varchar("name"),
  // ... existing fields
  
  // API rate limiting fields
  apiRequestsCount: integer("api_requests_count").notNull().default(0),
  apiRequestsResetDate: timestamp("api_requests_reset_date"),
  promoCodeUsed: integer("promo_code_used").notNull().default(0),
  isAdmin: integer("is_admin").notNull().default(0),
});


Field descriptions:

•
apiRequestsCount - Number of AI edits used this month (default: 0)

•
apiRequestsResetDate - Date when counter will reset (null on first use)

•
promoCodeUsed - Whether promo code was used (0 = no, 1 = yes)

•
isAdmin - Admin flag (0 = regular user, 1 = admin with unlimited access)




Step 2: Run database migration

In Replit Shell:

Bash


npm run db:push


Expected output:

Plain Text


✓ Pushing schema changes to database
✓ Added column: api_requests_count
✓ Added column: api_requests_reset_date
✓ Added column: promo_code_used
✓ Added column: is_admin
