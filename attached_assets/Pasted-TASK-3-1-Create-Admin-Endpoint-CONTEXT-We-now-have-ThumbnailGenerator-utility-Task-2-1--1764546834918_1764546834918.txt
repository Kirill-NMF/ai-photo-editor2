GOAL

Create POST /api/admin/generate-thumbnails endpoint that finds images without thumbnails and generates them.

IMPLEMENTATION

Add Endpoint to routes.ts

File: server/routes.ts

Add this import at the top:

TypeScript


import { generateThumbnailsBatch } from "./thumbnailHelpers";
import { isNull } from "drizzle-orm";


Add this endpoint (anywhere in the file, e.g., after other /api/images routes):

TypeScript


/**
 * Admin endpoint: Generate thumbnails for images that don't have them
 * Processes up to 10 images per request to avoid overwhelming the system
 * Can be called multiple times to process all images
 */
app.post("/api/admin/generate-thumbnails", async (req, res) => {
  try {
    console.log('[Admin] Manual thumbnail generation triggered');

    // Find images without thumbnails (limit to avoid overwhelming system)
    const imagesToProcess = await db
      .select({
        id: images.id,
        originalUrl: images.originalUrl,
      })
      .from(images)
      .where(isNull(images.thumbnailUrl))
      .limit(10);  // Process 10 at a time

    if (imagesToProcess.length === 0) {
      console.log('[Admin] No images to process. All thumbnails up to date!');
      return res.json({
        success: true,
        message: 'No images to process. All thumbnails up to date!',
        processed: 0,
        errors: 0,
      });
    }

    console.log(`[Admin] Found ${imagesToProcess.length} images without thumbnails`);

    // Generate thumbnails in batch
    const stats = await generateThumbnailsBatch(imagesToProcess);

    console.log(`[Admin] Complete! Processed: ${stats.processed}, Errors: ${stats.errors}`);

    res.json({
      success: true,
      message: `Processed ${stats.processed} images, ${stats.errors} errors`,
      processed: stats.processed,
      errors: stats.errors,
      remaining: imagesToProcess.length === 10 ? 'More images may need processing' : 'All done',
    });

  } catch (error) {
    console.error('[Admin] Error generating thumbnails:', error);
    res.status(500).json({
      error: 'Failed to generate thumbnails',
      message: error instanceof Error ? error.message : 'Unknown error',
    });
  }
});

USAGE

Process all images without thumbnails:

Bash


# Run multiple times until all processed
while true; do
  response=$(curl -s -X POST http://localhost:5000/api/admin/generate-thumbnails )
  echo "$response"
  
  # Check if no more images to process
  if echo "$response" | grep -q "No images to process"; then
    echo "All done!"
    break
  fi
  
  # Wait 2 seconds before next batch
  sleep 2
done


Check status:

Bash


# Count images without thumbnails
curl -s http://localhost:5000/api/admin/generate-thumbnails | jq '.processed'


NOTES

•
Batch size: 10 images per request (configurable via .limit(10 ))

•
Idempotent: Safe to call multiple times

•
No authentication: Add auth check if needed for production

•
Error handling: Errors logged but don't stop batch processing

OPTIONAL: Add Status Endpoint

If you want to monitor progress, add this endpoint:

TypeScript


app.get("/api/admin/thumbnail-status", async (req, res) => {
  const total = await db.select({ count: sql`count(*)` }).from(images);
  const withThumbnails = await db
    .select({ count: sql`count(*)` })
    .from(images)
    .where(isNotNull(images.thumbnailUrl));
  
  const totalCount = Number(total[0].count);
  const thumbnailCount = Number(withThumbnails[0].count);
  const percentage = ((thumbnailCount / totalCount) * 100).toFixed(1);
  
  res.json({
    total: totalCount,
    withThumbnails: thumbnailCount,
    withoutThumbnails: totalCount - thumbnailCount,
    percentage: `${percentage}%`,
  });
});
