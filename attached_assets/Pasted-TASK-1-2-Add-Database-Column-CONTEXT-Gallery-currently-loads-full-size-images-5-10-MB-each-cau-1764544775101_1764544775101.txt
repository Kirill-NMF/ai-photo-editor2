IMPORTANT NOTES
Why nullable?
Column is nullable (no .notNull()) because:
Existing images don't have thumbnails yet
Thumbnails are generated asynchronously
Gallery has fallback to currentUrl
Why TEXT type?
URLs can be long (GCS paths with tenant prefixes)
TEXT has no length limit (vs VARCHAR)
Standard for URL storage in PostgreSQL
Backward compatibility
Existing images will have thumbnailUrl = null
Gallery will use fallback: thumbnailUrl || currentUrl
No breaking changes to existing code
